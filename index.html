Snoop37, with its screen on the USB cable

This is Snoop37 (SLOOP for the M-Vave SMK-37 Pro) built with the screen mirror. It plays the same. It also sends its screen on the USB cable, for a snoopview screen.

Install on the keyboard

Snoop37 2.8.5 with the mirror (SNOOP_MIRROR=1), for the SMK-37 Pro

Open the installer

The installer page is SLOOP's own page. Its text says "FM-1": it is the same installer, and this package goes only on an SMK-37 Pro.

Experimental firmware, not from M-Vave, no warranty. You install it at your own risk.

Steps

  1. Use Chrome or Edge on a computer.
  2. Connect the SMK-37 Pro to the computer with a USB data cable. Close other apps that use MIDI.
  3. Click Open the installer, then Install. Let the browser use the MIDI devices.
  4. Do not unplug the cable while it writes. The keyboard restarts when it is done.
  5. Connect the keyboard to the snoopview board's "High speed USB" port.

Projects, presets, samples and settings stay on the keyboard.
